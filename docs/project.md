# Memory Curator Agent (记忆策展 Agent)

一个面向个人长期记录与深度回顾的记忆整理工具。系统不以“海量堆积”为目标，而是强调对个人素材的持续“策展”，帮助用户在日常记录中理清头绪、在周度回顾中看见阶段变化、在长期追踪中洞察行为/情绪模式。

## 核心使用节奏与输入分类

- **日输入（短期/日常流动）**：
  - **Todo 计划**：日度待办与任务安排。
  - **随记**：随时记录的灵感、情绪碎片、瞬间感受与日常碎碎念。
  - **日记**：对一天的系统总结与主观感悟。
- **长期输入与追踪**：
  - **笔记**：结构化的知识、深度思考、读书感悟或长期规划（不局限于单日，作为长期知识与思考沉淀）。
  - **人物关系档案**：支持添加人物关系（如女朋友、家人、合作伙伴等），维护基本消息（生日、喜好、关键纪念日等）并归档聊天记录，以便追踪关系互动与演变。
    - **聊天记录（日输入）**：导入微信等日常沟通对话碎片，记录即时的互动状态。
    - **聊天记录（长期输入）**：关联至特定人物关系或长期主题的深度对话历史，用于沉淀核心互动记忆。
- **周整理**：自动提炼一周计划完成度、主观感受波动、重复主题和关键事件，形成有复盘价值的周度回顾。
- **长期追踪**：提炼长期主题（职业、关系、创作等），基于长期输入（笔记、人物关系、聊天归档）追踪叙事变化与心理张力。

## 核心 Agent 能力

- **输入理解**：根据日输入和长期输入，自动判断文本用途（计划、随记、日记、笔记、聊天记录等）并进行结构化归属与时间/空间/人物多维映射。
- **人物与关系建模**：识别并提取文本或聊天记录中提及的人物、互动事件与情感状态，自动织入相应的人物关系档案，沉淀人物基本消息。
- **记忆命名与关联**：将重要碎片命名并建立有意义的线索连接（如特定笔记与某人物、特定随记与某长期主题的关联），而非生硬的标签堆叠。
- **模式与冲突识别**：识别重复出现的行为模式与决策倾向，发现关系互动中的变化趋势、叙事冲突及未完成议题，辅助自我理解。
