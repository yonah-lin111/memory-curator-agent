# 记忆策展 Agent

## 项目概览

记忆策展 Agent 不只是替用户被动记住说过的话，而是帮助用户把每天的计划、过程记录、主观感受与长期主题放进同一套可回顾的个人工作台。它面向持续记录、周期回顾与意义提炼场景，既支持日常执行层面的 todos、notes、journal，也输出被命名、被串联、可追踪的个人记忆线索，而不是一次性的摘要。

## 项目定位

- 角色：个人日常记录与长期素材策展助手
- 目标：把每日输入整理成可执行的日视图、可回看的周度回顾，以及可追踪的长期主题与变化轨迹
- 差异：强调计划、事实记录、主观感受与主题洞察的一体化组织，不做通用团队协作工具，也不做纯归档型笔记系统

## 目标用户

- 有稳定记录习惯，但难以长期回顾的人
- 想把计划、随记、日记与聊天素材放到同一套个人系统里的人
- 需要将人生素材转化为主题洞察的创作者、咨询者或深度思考者

## 核心价值

1. 把每日计划、事实记录与主观感受统一纳入同一套记忆策展体系，而非分散在多个工具中。
2. 从零散素材中提炼长期主题，而非停留在单条记录层面。
3. 识别重复出现的行为模式、情绪波动与决策倾向。
4. 发现用户叙事中的冲突、断裂与未完成议题。
5. 为重要记忆片段命名并建立关联，形成可持续追踪的个人脉络。

## MVP 能力边界

- 支持文本输入、聊天内容粘贴与 LLM 识别输入（含截图内容理解与文本提取）
- 支持每日 todo 计划、自由笔记与日记记录
- 支持当日计划视图、笔记列表、日记条目查看
- 以“日输入 + 周整理 + 长期追踪”为核心使用节奏
- 支持周度策展与长期主题追踪、变化对比
- 暂不覆盖音视频原始理解、多人协作、复杂自动化集成、提醒系统与富文本编辑器
