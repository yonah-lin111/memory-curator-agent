# Memory Curator Agent (记忆策展 Agent)

一个面向个人长期记录与深度回顾的记忆整理工具。系统不以“海量堆积”为目标，而是强调对个人素材的持续“策展”，帮助用户在日常记录中理清头绪、在周度回顾中看见阶段变化、在长期追踪中洞察行为/情绪模式。

## 核心使用节奏

- **日输入**：统一接纳 Todo 计划、随记、日记和笔记，支持导入微信聊天记录、截图提取等。
- **周整理**：自动提炼一周计划完成度、主观感受波动、重复主题和关键事件，形成有复盘价值的周度回顾。
- **长期追踪**：提炼长期主题（职业、关系、创作等），追踪叙事变化与心理张力。

## 核心 Agent 能力

- **智能输入理解**：自动判断文本用途（计划、事实记录、情绪表达等）并进行结构化归属。
- **记忆命名与关联**：将重要碎片命名并建立有意义的线索连接，而非生硬的标签堆叠。
- **模式与冲突识别**：识别重复出现的行为模式与决策倾向，发现叙事冲突及未完成议题，辅助自我理解。
